# MetryCAD

Versión afinada de [SolidCraft](https://github.com/tangency-labs/solidcraft) (código MIT OR Apache-2.0): CAD isométrico y suite civil.

- `build/construir-solidcraft.ps1`: clona SolidCraft en el commit fijado (bb08447c, v0.46.2), aplica `metrycad.patch` y compila los instaladores en Windows.
- `metrycad.patch`: todos los cambios de MetryCAD sobre ese commit.
- `src-nuevo/`: copia legible de los archivos nuevos (temas y grabador de macros).
- `logo/`: logo, icono e .ico.
- `NOTICE-MetryCAD.md`: atribución. El nombre y logo de SolidCraft no se usan.
